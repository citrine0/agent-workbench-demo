# 策略边界

## 允许

- 读取用户本机已授权可见的岗位搜索结果。
- 读取岗位详情和 JD。
- 将岗位标准化为本地 JSON。
- 对岗位与简历/候选人画像做匹配打分。
- 输出推荐理由、缺口、风险和下一步建议。

## 需要用户确认

- 登录 BOSS。
- 使用已登录账号读取岗位结果。
- 保存求职 workflow memory。
- 针对单个岗位改写简历或申请材料。

## 禁止

- 自动投递。
- 自动打招呼。
- 批量联系招聘方。
- 自动聊天或交换联系方式。
- 绕过验证码、登录限制或风控。
- 抓取用户无权访问的数据。
- 编造简历经历、项目成果、指标或背书。
- 保存未确认的原始简历全文、私密沟通或 agent trace。

## 失败处理

出现以下情况时必须停止，并向用户说明需要人工处理：

- `boss` 命令不存在。
- `boss status` 显示未登录。
- 搜索或详情返回登录失效。
- 出现验证码、风控、人机验证。
- 返回数据缺少岗位 ID 或 JD。
